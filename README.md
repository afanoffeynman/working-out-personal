# Working Out Personal

A private Python application used by its operator to access
their own Oura account and analyze their own data locally.

The application downloads authorized data through the Oura API
and produces local JSON files, CSV files, and statistical reports.
It does not provide a public service or accept other users.

Health data and credentials are not published in this repository.
The application does not send health data to AI services.

This is an independent personal project, not an official Oura product.
