# Privacy Policy — Working Out Personal

This application is operated solely for its operator's personal use.

Data accessed:
With OAuth authorization, the application accesses the operator's
Oura sleep, readiness, activity, stress, resilience, workout, tag,
SpO2, and heart-health data, where available and authorized.

Purpose:
Personal statistical analysis and visualization using local Python.

Storage and security:
Downloaded data and derived reports are stored on the operator's
computer. OAuth credentials are stored separately in a local file
with restricted access permissions.

Sharing:
The application does not sell data or send downloaded health data
to third parties, AI services, or this public documentation repository.
It communicates with Oura to authenticate and retrieve data.

Retention and deletion:
Data must be retained only for the period necessary for purposes
permitted by the applicable Oura agreement. The current application
has no automatic expiration feature; the operator manages deletion
of downloaded files, derived reports, and any backup copies manually.

Access can be revoked through Oura. Revocation does not automatically
delete existing local copies.
